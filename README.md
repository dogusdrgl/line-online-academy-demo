# LINE Academy V2

Bu klasor temiz bir baslangic icin ayrildi.

## Hedef

Ilk olarak yalnizca su omurgayi saglam kuruyoruz:

- uye girisi
- misafir girisi
- coklu rol mantigi
- sag uye paneli
- cevrimici / cevrimdisi durumu

## Acmak

Yerel sunucu acikken su adrese git:

- `/v2/index.html`

Ornek:

- `http://localhost:3000/v2/index.html`

## Dosyalar

- `index.html`: arayuz
- `styles.css`: V2 gorunumu
- `src/app.js`: bootstrap
- `src/supabase.js`: Supabase erisimleri
- `src/store.js`: state
- `src/ui.js`: render ve event baglari
- `supabase-schema.sql`: V2 veritabani yapisi
